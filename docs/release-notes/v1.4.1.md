## tgproxy v1.4.1 — 修复一键唤起 Telegram 无效的问题

### 问题原因
「添加到 Telegram」按钮之前对 SOCKS5 节点生成的是 `tg://proxy?server=&port=` 链接。
Telegram 对 `tg://proxy` **要求必须带 MTProto 的 secret 参数**，缺 secret 的链接会被
直接忽略——表现就是点了没有任何反应。

### 修复
- SOCKS5 节点改用正确的深链 scheme：`tg://socks?server=&port=`
- MTProto 节点不变（`tg://proxy?...&secret=...` 自带 secret）
- 桌面版与安卓版同步修复

### 实测
在你这台机器上（Telegram Desktop Store 版 7.3.1.0）已验证：
`tg://socks?server=123.58.219.171&port=10808` 成功唤起 Telegram 并弹出
「添加代理服务器」窗口（SOCKS5，主机/端口已填好）。
