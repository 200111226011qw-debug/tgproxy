## tgproxy v1.2.0 — 自动剔除失效节点 + 一键唤起 Telegram

### 新特性
- **自动剔除不通 IP**：每轮测试后，不通的代理直接从列表剔除，列表只保留当前可用节点
- **跟随代理池自动更新**：按设定间隔（默认 10 分钟）自动重新抓取源池、重新测试、剔除失效节点，无需人工干预
- **一键唤起 Telegram Desktop（不跳网页）**：列表内新增「添加到 Telegram」按钮，点击直接通过 `tg://proxy` 协议唤起本机 Telegram Desktop 弹出「添加代理」窗口——SOCKS5 自动构造 server/port 链接，MTProto 自带 secret，点 ADD 即完成
- **统计卡调整**：可用 / 不通已剔除 / 已排除 / 本轮测试
- 安卓版同步：点击列表任意条目（SOCKS5 / MTProto）直接弹出 Telegram「添加代理」窗口；未安装 Telegram 时降级复制链接

### 安全说明
桌面版唤起接口 `POST /api/open_telegram` 只接受当前可用列表中存在的 host:port，不接受任意链接。
