## TGProxy v2.3.0

桌面端一轮大版本：MTProto 真握手、镜像竞速、列表新鲜度。安卓已分别发在
android-v2.3.0 / android-v2.4.0，本版把桌面欠的这些一次性补上。

### 🔍 MTProto 真握手（不再「端口通就算过」）

`tg://proxy` 节点原来只做 TCP 探活，端口开着就记通过——透明代理、劫持设备、随便一个
acceptance server 都能骗过去。现在直连节点发 64 字节 obfuscated2 头 + `req_pq_multi`，
要求对端回一个**带我们随机 nonce 的 `resPQ`**（constructor `0x05162463`），假节点伪造不出。

- 结论三态：`ok`（握手成功 + RTT）/ `fail`（超时、协议错、假节点）/ `unavailable`（缺 secret、`ee`/FakeTLS 未实现，不计失败）
- 统计 `in_pool` / `candidates` / `tested`，能区分「源里没 MTProto 节点」和「全被 TCP 预筛刷掉」
- 与安卓版字节级对齐（反向切片、init 尾只发密文但状态推进 64 字节、服务端方向流从 0 开始）

### ⚡ 镜像竞速 + 并发提升

- 抓取从「直连失败才回退镜像」改为直连 + 3 个 jsDelivr 镜像**错峰并发竞速**，首个通过完整性校验的候选胜出
- 完整性下限：单响应 ≥64 字节且含至少一条非注释行，否则判失败（堵住「200 空体静默吞下」）
- TG 实测并发 100 → 300（Phase 2 基准实测：该负载下线程池优于原生 asyncio）

### 🕒 列表新鲜度

新增 `fetch_meta`：上报列表缓存年龄（取**最旧源**口径，避免陈旧镜像被新鲜镜像掩盖），
界面显示「多久前更新」，超过 1 小时改用小时显示。jsDelivr 的 `Age` 头是唯一可编程读取的新鲜度信号。

### 🔧 修复

- AES 后端并发首次解析竞态（首轮大量假 `CRYPTO_UNAVAILABLE`）
- `ee`/FakeTLS 记「无法判定」而非「失败」（不再把主流格式节点连败拉黑）
- secret 单路径解析（不再二次反解导致百分号编码的 secret 被误判）

### 测试

- 桌面 **254 passed**（MTProto 握手 31 + 接线 15 + freshness + UI 标签 + 变异工具自检等）
- 变异自检 **10/10**：把实现改错（反向切片改顺序 / 去 nonce 校验 / ee 短路失效等），目标测试必红
- MTProto 与安卓版**跨语言黄金向量对拍**（四密钥、加密 init 尾、请求帧、服务端响应逐字节相等）

### 已知边界

- `ee` / FakeTLS 未实现（记未验证，不计失败）
- 未在真机连过 Telegram（沙箱无到 Telegram 的出口，四个 DC 全超时）
- 源自动体检换源与爬虫模式仍是桌面独有（安卓未移植）
