## TGProxy v2.2.1

桌面端修复 + 布局整理。**安卓无变化**（仍为 v2.1.0 的 Debug 包）。

### 🐛 修复：微软商店版 Telegram 无法一键唤起

商店版（AppX）Telegram **不写** `shell\open\command`，Windows 通过 AppX 清单在运行时
解析协议。旧版本只看注册表，据此判定「协议未注册」并**拒绝唤起** —— 对商店版用户
是永远唤不醒的假阴性，还被告知「协议坏了」。

现在改为：一律先真的尝试唤起，注册表查不到只作为「额外提示」，同时把可复制的
`tg://socks?...` 链接一并给出来。两头都不亏。

### 📁 布局：变成真正的绿色便携版

配置、节点缓存、拉黑名单、轮次日志、运行日志统一收进 `data/` 子目录：

```
tgproxy.exe
data\  config.json  known_good.json  known_bad.json
       source_health.json  rounds.jsonl  tgproxy.log
```

旧版本平铺在程序目录里的文件会在首次启动时自动搬进去（不覆盖已有、可重复执行）。
**整个文件夹拷走即完成迁移**，插到任何电脑上都能用。

### ⚡ 优化：堵住内置窗口的磁盘膨胀

`--app` 模式复用系统浏览器，其 profile 默认不设上限 —— 实测长到 **485 MB**
（Default 393M + 组件缓存 25M + 各类 Edge 模型若干）。已加三条限制：
磁盘缓存上限 128 MB、禁用后台联网、禁用组件更新。

测试残留文件不再散落在程序目录。
