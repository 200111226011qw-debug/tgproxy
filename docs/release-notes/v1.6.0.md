## tgproxy v1.6.0 — 源自动体检与换源（垃圾源自愈）

### 新特性：软件自己管理数据源
- **逐源健康度**：每轮 TG 实测后，按"合并时首次贡献源"归属统计每个源的 TG 验证产出，落盘 `source_health.json`
- **自动停用**：连续 3 轮抓取失败，或最近 3 个有产出轮次全部 0 个 TG 可用节点 → 该源自动停用
- **自动补位**：停用后从内置候选池（10 个备选：proxyspace / vakhov / geonode JSON / socks-proxy.net 爬虫源 / TheSpeedX 系大列表等）按顺序补位；已判垃圾的候选不回用；至少保留一个活跃源
- **持久化**：变更写回 config.json，重启仍生效；界面页脚黄色 notice 条提示每一次停用/补位

### 实测
- 离线验证：停用（0 产出/抓取失败两种原因）、按序补位、配置回调、全停用保护，全部通过
- 实跑一轮：health 落盘逐源产出 hideip **18** / proxyscrape **3** / TheSpeedX **2** / monosans **1** / watchttvv **0**——与此前 13 源人工体检排名一致，说明自动体检的归因是准的
- 本轮 24 个可用节点全部 <1s（最快 203ms）
