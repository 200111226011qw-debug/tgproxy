## TGProxy v2.2.0

桌面端体验补丁。**只改了桌面，安卓无变化**（仍为 v2.1.0 的 Debug 包）。

### 独立窗口，不再弹浏览器标签

双击 exe 后打开的是一个**没有地址栏、没有标签页**的独立窗口，而不是往默认浏览器里塞一个标签。

实现方式：复用系统已安装的 Edge / Chrome 的 `--app` 模式。**没有引入任何第三方依赖**
（exe 只增加 547 字节）—— 项目仍然保持「纯 Python 标准库、零第三方依赖」。

### 关掉窗口就退出

页面关闭时上报，服务端 3 秒宽限后停止；期间只要还有页面在轮询就取消退出
（刷新页面、多开标签都不会误杀）。

### 唤起 Telegram 失败时给出可复制的链接

以前点「添加到 Telegram」失败只显示一句「唤起失败」。现在：
- 有 `tg://` 链接 → 面板里给出可复制的输入框
- 没有链接（如代理已不在列表）→ 只显示真实原因，不再留一个点了没反应的复制按钮
- 本地服务已退出 → 明确提示「无法连接本地服务」
