## tgproxy Desktop v1.9.0 — 连败拉黑

### 新特性
**连败拉黑（与安卓 v2.1.0 同步）**：IP 池里**连续 3 轮都不通**的节点自动拉黑 48 小时、跳过测试，节省筛选时间：

- TCP 预筛不通或 TG 两关未过 → 连败 +1；两关通过（含超门槛——通只是慢）→ 清零
- 连败 3 轮 → 拉黑 48 小时，期间该节点直接跳过测试；到期自动解封重测（免费池 IP 会轮换/复活）
- 拉黑表持久化 `known_bad.json`，超 10000 条按最久未失败淘汰
- 界面统计区新增「**连败拉黑（跳过测试）**」（独立于本轮测试总数）

### 验证
- 8 个新回归用例（连败达标/通过清零/48h 解封/落盘回读/损坏容忍/容量淘汰 + 2 个整链路场景），全 **18 测试绿**
- 打包 exe 冒烟：/api/proxies 返回 blacklisted 字段 ✓
