## tgproxy v1.1.0 — 多数据源 + 镜像回退

### 新特性
- **多数据源并发抓取**：内置 6 个免费代理源（新增 monosans、TheSpeedX、hookzof、zevtyardt、proxifly），按 host:port 全局去重合并
- **jsDelivr 镜像自动回退**：raw.githubusercontent.com 直连失败时自动依次回退 cdn / gcore / fastly 镜像，国内网络可用性大幅提升
- **兼容裸 host:port 列表**：TheSpeedX / monosans 等主流无 scheme 格式直接可用（按 SOCKS5 处理）
- **智能抽样**：单源 >1000 条、合并 >3000 条随机抽样，单轮刷新控制在分钟级（桌面版测试并发 20 → 150）
- **桌面版页脚**：实时展示每个数据源状态（成功条数 / 失败原因 / 是否走镜像）

### 实测数据（2026-10-24，国内网络）
- 6 个源全部抓取成功，合并去重 3000 条参与测试
- 一轮刷新约 80 秒，测得 **889 条可用**，最快节点 18 ms
