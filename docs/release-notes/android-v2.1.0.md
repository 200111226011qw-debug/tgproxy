## tgproxy Android v2.1.0 — 仪表盘视觉 + 连败拉黑

### 新特性
**1. 连败拉黑（与桌面 v1.9.0 同步）**：IP 池里**连续 3 轮都不通**的节点自动拉黑 48 小时、跳过测试，节省筛选时间——免费池 IP 会轮换，到期自动解封重测；两关通过（含超门槛）即清零连败。拉黑表持久化，超 1 万条按最久未失败淘汰。统计卡新增红色「**已拉黑**」段（独立于本轮测试总数）。

**2. 仪表盘视觉（参考深色数据仪表盘风格重做）**：
- 深藏青底色系 + 蓝→青**渐变 Hero 大卡**：「可用节点」大数字 + 最优延迟 + 上轮耗时 + 下次更新倒计时；刷新中自动变为阶段进度（抓取 → TCP 预筛 → TG 实测）
- **五段统计卡**：TG 未过 / 超门槛 / TCP 不通 / 已拉黑 / 已排除
- 节点卡：左延迟色条 + 等宽地址 + 延迟胶囊 + **渐变「⚡ 使用」按钮** + 圆底复制按钮
- 界面全面中文化（标题「TG 代理」）

### 实机验证（雷电模拟器 1280×720）
- 一轮完整刷新：测试 2253 个 → 保留 1 个（812ms），口径自洽：TG 未过 333 + 超门槛 35 + TCP 不通 1884 + 保留 1 = 2253
- 「使用」按钮 tg:// 深链唤起验证通过；known_good 启动先行展示、分阶段进度、下拉刷新、设置弹层全部可用
- 测试：11 类 85 例 × debug/release 双变体 = **170 全绿**

### 口径说明
available + unverified + tgFailed + overThreshold + dropped = tested（本轮 TCP 预筛总数）；已拉黑节点不计入 tested。

### 安装
下载下方 `tgproxy-android-v2.1.0.apk` 安装（debug 签名；升级安装覆盖 v2.0.0，沉淀与拉黑数据自动沿用）。
