## tgproxy v1.8.0 — known_good 沉淀开关（自动保存可用节点，可关）

### 新特性
设置区新增「**自动保存可用节点（known_good）**」开关（默认开）：

- **开启**（默认）：每轮 TG 验证通过的节点写入 `known_good.json`，下轮优先复测并保留——现有行为不变
- **关闭**：不再读取、不再写入 `known_good.json`（已有文件保留不动），每轮从源池全新取样；重新开启即恢复使用旧文件
- 开关状态持久化到 `config.json`（`known_good_enabled`），重启仍生效；POST `/api/settings` 同步支持（非布尔值返回 400）

### 实测三态
| 状态 | 行为 |
|---|---|
| 默认开 | 写盘 ✓ 合并 ✓ |
| 关闭 | mtime 不变 ✓ 不补入 ✓ 节点列表不受影响（14 个可用正常展示） |
| 重新开启 | 旧文件恢复使用 ✓ 重新沉淀 ✓ |

### 顺带修复
- `config.json` 里 `known_good_enabled` 的字符串形式（"true"/"false"/"0"/"1" 等）宽容转换；非法值回退默认开
