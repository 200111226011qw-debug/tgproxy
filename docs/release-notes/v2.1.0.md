## TGProxy v2.1.0

双端 Telegram 免费代理管理器。桌面为 Python 标准库零依赖 + 本地 Web UI，
安卓为 Kotlin/Compose 原生应用。

### 本版重点

- **性能**：桌面端在 2026-10-28 基准环境下，中位耗时 127.63s → 44.76s，
  单位耗时 57.0 → 21.9 ms/节点（同一会话内重测，测数 2151 → 2043 基本持平）。
  手段：TCP 预筛超时按延迟门槛派生、剪掉必然超门槛的第二关、
  TG 两关拆独立预算、TCP 并发 150 → 300。
- **可观测性**：分阶段耗时（fetch / prepare / tcp / tg / commit）、
  TG 两关漏斗（DC 失败 / 超门槛 / 站点失败 / 通过）、按轮留存的 `rounds.jsonl`。
- **双端契约**：`Stats` / `StageDurations` / `TgGateStats` / `RoundRecord`
  字段同名同义，两端日志可直接比对。
- **UI**：桌面三栏控制台；安卓三页签（仪表盘 / 节点列表 / 日志）。

### 质量

- 207 个单测全绿（桌面 82 pytest / 安卓 125 JUnit）
- 关键修复均做过变异自检（故意改坏 → 确认测试变红）

### 已知边界

- 安卓为 **Debug 签名包**，未建 release keystore；源码可直接构建
- 本轮 UI 改动未做视觉验收（三页签 / 日志页 / 倒计时拆分）
- 安卓无当前版本的真机计时基线，性能收益未测量
