# 版本发布管理客户端

一个自包含的单文件客户端，把「创建新版本」重新设计为**完整的软件发布流程**：创建 → 编辑 → 发布 → 取消发布，而非简单新增一条记录。

## 运行方式

无需安装任何环境、无外部依赖（零 CDN，完全离线可用）：

- **直接双击 `index.html`** 用浏览器打开（Chrome / Edge / Firefox 均可），或拖入浏览器窗口
- 数据保存在浏览器本地（localStorage），关闭再打开不丢失；换浏览器/清缓存前请先**导出数据**

## 功能一览

### 版本字段
| 字段 | 规则 |
|---|---|
| 版本号 | 必填；全局唯一（不区分大小写）；仅允许字母、数字及 `. _ + -`，最长 32 位 |
| 版本类型 | 必填；正式版 / 测试版 / 预览版 / 补丁版 |
| 发布时间 | 发布前必填；创建时默认当前时间，可修改（datetime-local 原生选择器） |
| 发布说明 | 发布前必填；多行文本，最长 2000 字 |

### 状态机与流转
```
草稿 ──发布──▶ 已发布 ──取消发布──▶ 已下架
 ▲                                    │
 └────────────── 重新发布 ◀───────────┘
```
- **草稿**：可继续编辑全部字段，可执行发布
- **已发布**：版本号 / 类型 / 发布时间**锁定**（保证发布记录不可篡改），仅可补充发布说明或取消发布
- **已下架**：可编辑、可重新发布（重新发布会再次执行完整校验）

### 校验逻辑
- **唯一性**：版本号全局唯一，创建与编辑时均校验（编辑时排除自身）
- **必填项**：保存草稿校验版本号 + 类型；执行发布（含「保存并发布」「重新发布」）额外校验发布时间 + 发布说明
- **状态流转**：按钮按当前状态呈现，非法流转在代码层拦截（`TRANSITIONS` 表）；从卡片直接点「发布」但字段不全时，自动打开编辑弹窗并逐项展示错误，不会静默失败

### 空状态
- 无任何版本时展示「**暂无发布版本**」+ 创建入口
- 按筛选标签分别展示：暂无已发布版本 / 暂无草稿版本 / 暂无已下架版本

### 其他
- 顶部统计：已发布 / 草稿 / 已下架 / 总数；筛选标签带计数
- 排序：已发布（按发布时间倒序）→ 草稿 → 已下架
- **导出 / 导入** JSON：导出一条文件便于备份与分发；导入时版本号缺失或已存在的条目自动跳过并提示数量
- 列表按发布时间、发布完成/下架时间展示；取消发布有二次确认

## 技术说明

- 原生 HTML / CSS / JavaScript，单文件约 700 行，无构建、无框架、无网络请求
- 存储：`localStorage`（键 `version-release-client.data.v1`），读写均做异常兜底
- 安全：所有用户内容渲染前经 HTML 转义，无 XSS 注入面
- 兼容：现代浏览器（用到 `datetime-local`、`closest`、`Blob` 等标准 API）
